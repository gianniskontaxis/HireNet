HireNet – Recruitment Management System

*Overview
HireNet is a recruitment management system designed to support companies in managing job applications, candidate data, and hiring processes efficiently.

*Features
- Job posting and management  
- Candidate application tracking  
- Data management for applicants  
- User-friendly interface for recruitment processes  

*User Roles
- Administrators: manage the system and job postings  
- Users: apply for jobs and track applications  

*Technologies Used
- Java
